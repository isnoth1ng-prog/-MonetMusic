# Monet Music

Современный iOS музыкальный плеер с матовым премиальным дизайном, вдохновленный Apple Music и Yandex Music.

## Особенности
- **Рабочее воспроизведение**: Запускайте треки, и они будут играть. Используется публичный API iTunes (для 30-секундных превью в качестве прототипа, но архитектура позволяет легко подключить другой сервис).
- **Поиск**: Поиск песен, артистов и альбомов.
- **Моя волна**: Бесконечный поток музыки на основе ваших предпочтений.
- **Медиатека (SwiftData)**: Добавляйте любимые треки в локальную базу данных.
- **Фоновое воспроизведение**: Музыка продолжает играть даже при заблокированном экране или свернутом приложении. Интеграция с Control Center.
- **Тексты песен**: Красивый экран с текстами песен.
- **Премиум UI**: Стекло, матовые поверхности, плавные анимации и ambient-фоны, адаптирующиеся под обложку трека.

## Как запустить проект в Xcode
Поскольку проект сгенерирован полностью в виде исходных файлов без жесткой привязки к `.pbxproj`, самый надежный способ запустить его:

1. Откройте **Xcode** на вашем Mac.
2. Выберите **File > New > Project...**
3. Выберите вкладку **iOS** и шаблон **App**. Нажмите Next.
4. Назовите проект **MonetMusic**. 
   - Interface: SwiftUI
   - Language: Swift
   - Storage: SwiftData (или None, так как SwiftData инициализируется программно в коде).
5. Нажмите Next и создайте проект.
6. В созданном проекте удалите файлы `ContentView.swift` и `MonetMusicApp.swift`.
7. Перетащите все файлы из папки `Sources` (которую вы видите рядом с этим README) прямо в Xcode, в папку вашего проекта. Убедитесь, что стоит галочка "Copy items if needed".
8. **Очень важно для фонового аудио:** 
   - Нажмите на проект (MonetMusic) в левом меню навигатора.
   - Перейдите на вкладку **Signing & Capabilities**.
   - Нажмите **+ Capability** и добавьте **Background Modes**.
   - Поставьте галочку возле **Audio, AirPlay, and Picture in Picture**.
9. Выберите симулятор (например, iPhone 15 Pro) или подключенный iPhone.
10. Нажмите **Run (Cmd+R)**.

## Архитектура
Проект построен с использованием современной архитектуры SwiftUI и MVVM:
- **Core/Models**: Модели данных (`Track`, `Album` и т.д.).
- **Core/Persistence**: Локальное хранение с помощью `SwiftData` (`LibraryTrack`).
- **Core/Services**: Протокол `MusicService` и его реализация `ITunesMusicService`.
- **Core/Audio**: `AudioPlayerService` на базе `AVPlayer`. Управляет очередью и фоновым режимом (`MPNowPlayingInfoCenter`).
- **Features**: Экраны, разбитые по функциональности (Home, Wave, Search, Library, Player).

## Замена источника музыки (API)
В данный момент используется публичный `ITunesMusicService`. Чтобы подключить другой API (например, Spotify, Apple Music API или ваш собственный сервер):
1. Создайте новый класс, реализующий протокол `MusicService`.
2. В файлах `SearchView.swift`, `HomeView.swift`, `LyricsView.swift` и `MyWaveView.swift` замените `private let musicService: MusicService = ITunesMusicService()` на ваш новый сервис.
3. Реализуйте маппинг данных из вашего API в структуры `Track`.
